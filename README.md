# AI 模型档位曲线

把 [Artificial Analysis 模型排行榜](https://artificialanalysis.ai/zh/leaderboards/models) 做成可交互的档位曲线：横轴单任务价格，纵轴智能指数，同一模型各档位连线。

> **仓库不含任何榜单数据。** 数据只保存在你本机的 `data/` 目录（已被 Git 忽略），clone 后必须先手动运行一次脚本才能使用。
>
> 抓取前请自行阅读 Artificial Analysis 的[使用条款](https://artificialanalysis.ai/terms-of-use)：其中禁止用脚本自动查询或抓取该站数据，也禁止复制、再发布站点内容。本项目与 Artificial Analysis 无关，未获其授权；是否运行脚本及由此产生的责任由使用者自行承担。请勿提交、分享或公开 `data/` 里的内容与含数据的导出图。

## 使用

只需要 Python 3.9 或更新版本，无需安装依赖。

**1. clone 后手动取一次数据**（约 1 分钟，写入本机 `data/`）

```bash
git clone https://github.com/1010323691/model-effort-curves.git
```

```bash
cd model-effort-curves
```

```bash
python3 -I scripts/update_data.py
```

**2. 打开看板**

| 打开方式 | 看图 | 页面内更新 |
|---|---|---|
| 双击 `启动看板.command`（macOS，推荐） | 可以 | 可以 |
| 运行 `python3 -I scripts/serve.py` | 可以 | 可以 |
| 双击 `index.html` | 可以，离线可用 | 需要先启动服务，页面会给出提示并自动切换 |

没有数据时页面只显示取数命令，不会自动抓取。

## 更新数据

已有数据后，可以再次运行上面的脚本；也可以通过本机服务打开看板，点右上角“更新数据” → “从原站更新”。约 1 分钟。

- 更新期间可以继续看图，也可以取消（开始写入后不可取消）。
- 完成后自动载入，保留视图、筛选、固定的模型、滚动位置和撤销历史，并列出新增、移除和数值变化。
- 其他标签页会提示“有新数据”，不会打断正在看的内容。
- 启动窗口关闭即停止服务。服务只监听 `127.0.0.1`。
- 保存的视图和主题按打开地址分别存储：双击 `index.html` 与通过服务打开时各有一份。

以下情况会中止并保留旧数据：原站改版、数据格式异常、同一指数版本内数量骤降过半、超过两成详情页失败（打不开或解析不出该模型都算）。写入中途出错会回滚；写入时关闭终端会先写完再退出。

不超过两成详情页失败时照常更新：没取到的详情字段按配置 ID 沿用上一版，并在 `detailFrom` 记下来源时间，页面上也会标注。价格已变时不沿用成本构成，指数换版时不沿用成本与 Token。

| 文件 | 内容 |
|---|---|
| `data/models.csv` | 有智能分的配置，UTF-8 BOM，Excel 可直接打开 |
| `data/models.json` | 同上，另含各评测得分与成本构成 |
| `data/leaderboard-raw.json` | 榜单全部配置的原始字段 |
| `data/data.js` | 页面加载用 |
| `data/last-update.json` | 最近一次更新相对上一版的变化 |

## 数据口径

- **单任务价格**：AA 智能指数各评测任务的加权平均花费，不是每百万 Token 单价。
- **档位顺序**：非推理 → Low → Medium → High → Xhigh → Max。非推理档用虚线和空心点表示。
- **只用线性刻度**：同一张图里，相同距离永远代表相同差值。价格、耗时、智能等数值从 0 起，所以 10 倍数值就是 10 倍距离。不提供对数轴、滚轮缩放和拖动缩放。
- **拥挤区**：不压缩刻度，而是在全程图旁另画从 0 起的局部图（例如 `0–$5`、`0–$1`），上限随数据和筛选自动计算。同一张图内可以直接比距离，不同分图之间不可以。
- **等距量表**：日期和 Elo 类分数没有有意义的零点，只保证相同距离等于相同差值。
- **免费配置**：就在 0 处。
- **缺少价格的配置**：不进入以价格为轴的图，但保留在数据表和其他指标的图里。
- **最优前沿**：不存在“不更贵且更聪明”或“更便宜且不更差”的替代配置。
- **地区**：按厂商总部人工归类，不是原站字段；新厂商默认归入“其他地区”，需要时修改脚本顶部的 `CN` / `US`。
- **发布趋势**：只含当前仍在榜的模型，不代表完整历史。
- 只读取页面中的明文数据，不读取、不解密原站的加密数据文件。数据版权归 Artificial Analysis，不随本仓库分发。

## 测试

全部离线运行：用 `tests/fixture.py` 生成的虚构数据，不访问原站，也不读写你本机的 `data/`。

抓取脚本与本机服务：

```bash
python3 -I tests/test_update.py
```

浏览器里的交互与图表回归（需要 Node 22+ 和 Edge 或 Chrome，约 3 分钟，基准视口 1920×1080）：

```bash
node tests/browser.mjs
```

## 代码结构

| 文件 | 职责 |
|---|---|
| `assets/core.js` | 指标、状态、筛选、前沿、配色 |
| `assets/plot.js` | 线性比例尺、全程与局部分图、标签避让 |
| `assets/views.js` | 13 个视图 |
| `assets/ui.js` | 控件、交互、导出 |
| `assets/update.js` | 页面内更新：进度、取消、变更展示 |
| `scripts/update_data.py` | 抓取、校验、比对、回滚式写入 |
| `scripts/serve.py` | 本机服务与更新接口 |
